## 1. 처음 한 번만: 내 열쇠(패스키) 만들기

이 블로그는 비밀번호 대신 **패스키**로 로그인해요. 휴대폰 지문·얼굴 인식이나 Windows Hello(PIN)로 확인하는 방식이라 비밀번호를 외울 필요도, 털릴 걱정도 없어요.

1. 프로젝트 폴더의 **`secrets.local`** 파일을 열어 `ADMIN_SETUP_TOKEN=` 뒤의 값을 복사해요. (이 파일은 내 컴퓨터에만 있고 GitHub에는 안 올라가요)
2. https://studyblog.maeumssi.workers.dev/admin/setup 에 들어가요.
3. 설정 토큰을 붙여 넣고 **패스키 등록**을 눌러 지문·얼굴·PIN으로 확인해요.
4. 끝! 다음부터는 `/admin` → **패스키로 로그인** 버튼 한 번이면 돼요.

> 💡 휴대폰과 컴퓨터에 하나씩 등록해 두면 하나를 잃어버려도 안전해요. (관리자 화면 → 로그인·보안 → "이 기기에 패스키 추가")

## 2. 글 쓰는 법

1. `/admin` → **새 기록 쓰기**
2. 템플릿을 하나 고르거나 빈 칸에 바로 써요.
3. 오른쪽에서 **Day 번호**, **공부 시간**, **태그**를 채워요. (Day 번호는 자동으로 다음 번호가 들어가 있어요)
4. **발행하기**를 누르면 끝. 아직 덜 썼으면 **임시저장**.

- `Ctrl + S`로 언제든 저장돼요.
- 저장하기 전에 창이 꺼져도 브라우저에 임시 백업이 남아 있어서, 다시 열면 "불러오기"를 물어봐요.
- 발행 시각을 미래로 정하면 그 시각에 자동으로 공개돼요. (예약 발행)

## 3. 목표 · 계획 쓰는 법

1. `/admin` → **목표·계획** → 칸(이번 주 / 이번 달 / 장기 목표)에서 **목표 추가**
2. 목표, 메모, 마감일, 형광펜 색을 정하고 **단계**를 잘게 쪼개요.
3. 저장하면 `/goals` 목표 보드에 카드로 붙어요.
4. 로그인한 상태로 목표 보드에서 단계를 누르면 바로 체크돼요. 모든 단계를 끝내면 '달성' 도장이 찍혀요.

## 4. 내 컴퓨터에서 실행해 보기

처음 한 번만:

```bash
npm install            # 필요한 라이브러리 설치
npm run setup:local    # 내 컴퓨터용 비밀 값(.dev.vars)과 데이터베이스 준비, 예시 글 넣기
```

그다음부터는:

```bash
npm run dev            # http://localhost:4321 에서 열려요
```

- 내 컴퓨터의 데이터베이스는 연습용이라 배포한 사이트와 따로예요. 여기서 글을 써도 진짜 사이트에는 안 올라가요.
- 내 컴퓨터용 설정 토큰은 `npm run setup:local`이 마지막에 알려 줘요. (`.dev.vars` 파일에도 있어요)
- 끝낼 때는 `npx astro dev stop`

## 5. 고친 코드를 사이트에 올리기 (배포)

**글은 사이트에서 바로 쓰니까 배포가 필요 없어요.** 디자인이나 기능(코드)을 고쳤을 때만 해요.

```bash
npm run check          # 실수(타입 오류)가 없는지 확인
npm run deploy         # 빌드하고 Cloudflare에 올리기
```

데이터베이스 구조(`src/db/schema.ts`)를 바꿨다면, 배포 전에:

```bash
npm run db:generate        # 바뀐 부분을 migrations/ 폴더에 SQL로 만들어요
npm run db:migrate:local   # 내 컴퓨터 DB에 적용
npm run db:migrate:remote  # 진짜 사이트 DB에 적용
```

> ⚠️ `db:generate`가 만든 SQL에 `DROP TABLE`이 있으면 그대로 적용하지 마세요. 표를 지웠다 다시 만들면 연결된 댓글·태그가 사라질 수 있어요. 칸 하나를 더하는 거라면 `ALTER TABLE ... ADD` 한 줄로 고쳐 쓰는 게 안전해요. (`migrations/0001_goals_study_time.sql` 참고)

## 6. 백업

- **간단 백업:** 관리자 화면 → 블로그 설정 → **모든 글 백업 받기** (글·태그·페이지·댓글·목표가 JSON 파일로 내려받아져요)
- **전체 백업 (이미지 포함):** `npm run db:backup` → `backups/` 폴더에 SQL 파일이 생겨요.
- Cloudflare D1은 지난 30일 동안의 어느 시점으로든 되돌리는 기능(Time Travel)도 있어요.

## DB 설계 (Cloudflare D1 = SQLite)

| 표 | 하는 일 |
| --- | --- |
| `posts` | 글 (마크다운 원본, 변환된 HTML, Day 번호, 공부 시간, 상태: 임시저장/발행/휴지통) |
| `post_revisions` | 저장할 때마다 남는 옛 버전 (글마다 30개) |
| `post_redirects` | 글 주소를 바꿨을 때 옛 주소 → 새 주소 연결 |
| `tags`, `post_tags` | 태그, 글 ↔ 태그 연결 |
| `pages` | 소개 같은 고정 페이지 |
| `goals` | 목표 카드 (기간, 상태, 단계 목록, 마감일) |
| `comments`, `reactions` | 댓글, 반응 스티커 |
| `post_views_daily` | 하루 조회수 (관리자 그래프용) |
| `media`, `media_blobs` | 올린 이미지 정보, 이미지 파일 본체 |
| `settings` | 블로그 이름·소개 같은 설정 |
| `users`, `passkeys`, `sessions`, `auth_challenges` | 글쓴이, 패스키, 로그인 상태 |
| `rate_limits`, `audit_logs` | 도배 방지 카운터, 보안 기록 |

## 안전과 개인정보

- **비밀번호가 없어요.** 패스키는 공개 키만 서버에 저장되고 진짜 열쇠는 내 기기 밖으로 나오지 않아요.
- **로그인 쿠키**는 자바스크립트가 못 읽고(HttpOnly), https에서만 오가요. 서버에는 쿠키 값의 해시만 저장해요.
- **다른 사이트에서 몰래 보낸 요청(CSRF)** 은 막아요. 관리자 기능은 로그인한 사람만 쓸 수 있어요.
- **글 안의 HTML·스크립트는 실행되지 않아요.** (XSS 방지) 콘텐츠 보안 정책(CSP)으로 허락한 스크립트만 돌아가요.
- **도배 방지:** 로그인 시도, 댓글, 검색, 반응에 횟수 제한이 있어요. 댓글은 기본으로 "승인 후 공개".
- **방문자 IP는 그대로 저장하지 않아요.** 되돌릴 수 없는 해시로 바꿔서 도배 방지에만 써요.
- 비밀 값(`ADMIN_SETUP_TOKEN`, `HASH_SECRET`)은 코드에 없고 Cloudflare 비밀 값 · `.dev.vars` · `secrets.local`에만 있어요. 셋 다 GitHub에 안 올라가요.
- 실명·학교·연락처는 넣지 않았어요. 넣고 싶으면 관리자 화면 → 블로그 설정에서 직접 넣으세요.
